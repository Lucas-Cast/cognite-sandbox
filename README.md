# Python Playground

## Generate data model clients

Typed clients generated by the Industrial Model Generator are stored in
`src/core/data`. Each data model has its own subdirectory, which can be
regenerated when needed.

Before generating, create `.env` from `.env.example` and provide
`COGNITE_PROJECT`, `COGNITE_BASE_URL` (or `COGNITE_CLUSTER`), and
`COGNITE_ACCESS_TOKEN`. The generator requires a bearer token; it does not use
OAuth client-credentials directly.

Run this command from the repository root:

```powershell
uv run python src/core/data/generate_client.py
```

The terminal will ask for the CDF data model identifier (for example,
`my_space/MyDataModel/v1`), the generated client class name, and the directory name
to create under `src/core/data` (for example, `my_data_model`).

If the target directory already exists, the script asks for confirmation before
replacing it. Do not include tokens or other secrets in generated files or in Git.
